# # Proyecto NutriFresh S.A.S. - Optimización Logística

Este repositorio contiene los entregables de la solución analítica para NutriFresh S.A.S.

## 📂 Estructura del Proyecto
* `notebooks/NutriFresh_Modelo.ipynb`: Código con la simulación de datos, EDA, modelo Random Forest y métricas.
* `docs/Bitacora_NutriFresh.pdf`: Documento de bitácora con las justificaciones técnicas y teóricas.
* `docs/Informe_Ejecutivo.pdf`: Resumen de hallazgos para la gerencia.

## ⚙️ Tecnologías Utilizadas
* Python 3.10+
* Pandas, Scikit-Learn, Seaborn, Matplotlib.

## 🚀 Cómo ejecutar
1. Clonar el repositorio: `git clone https://github.com/tu-usuario/NutriFresh_Logistics_IA.git`
2. Abrir Jupyter Notebook: `jupyter notebook`
3. Ejecutar el archivo `NutriFresh_Modelo.ipynb` celda por celda.

## 📊 Resultados Principales
* El modelo Random Forest logró identificar correctamente los pedidos con alta probabilidad de retraso.
* Las variables más influyentes en los retrasos son el **Nivel de Tránsito** y la **Precipitación (Clima)**.
